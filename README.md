# Font Explorer

Static front-end project showcasing Google Fonts with:
- Search, filter, and sorting
- Live preview text + size controls
- Comparison tool (up to 3 fonts)
- Favorites and recently viewed (localStorage)
- Light/Dark theme toggle

## Run locally

Open `index.html` in a browser, or serve the project folder:

```bash
cd fonts
python3 -m http.server 4173
```
